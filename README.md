# VDS Ozon Media (free static site)
Source files: verified public EDON supplier-original photos only. Publication via isolated Netlify Free project `vds-ozon-media`; the source tree does not modify any live website.
No API credentials, passwords, stock levels, or internal price data here.
Images use content-addressed filenames, immutable Cache-Control, direct HTTP image/jpeg.
Official manufacturer picture URLs should be used first; this is the fallback for distributor-original files that have no stable direct source URL.
Never use temporary signed Yandex Disk download links in Ozon templates.
IMPORTANT: This is public content: place only images explicitly intended for reseller product listings.
